Executive Overview

Traditional cold email automation relies on static mail-merge templates that swap out {{firstName}} and {{company}}. Today's corporate spam filters and executive gatekeepers instantly recognize and discard these cookie-cutter emails. Conversely, bespoke manual research on every prospect consumes 15 to 30 minutes per lead, rendering large-scale outreach impractical.

This project architects an Autonomous AI Cold Outreach Agent using n8n as the orchestration hub. The system ingests uncontacted prospects from Google Sheets, performs real-time corporate intelligence queries using Tavily Search, synthesizes hyper-tailored pitch hooks using a local Ollama (LLaMA 3.2:1b) model, delivers emails through Gmail API OAuth2, and immediately notifies the sender on WhatsApp with complete dispatch metadata.

Key Breakthrough: 100% private, zero-token-cost local LLM inference paired with real-time web research, rate-limiting domain protection, and instant smartphone notifications.

Zero API Cost & Privacy via Local Ollama

Proprietary commercial APIs (such as GPT-4o or Claude 3.5 Sonnet) can quickly incur significant expenses when processing multi-step agent reasoning across hundreds of leads daily. Moreover, transmitting sensitive prospect information, internal pitch deck figures, and contact lists to third-party cloud models raises data privacy concerns.

This solution utilizes Ollama hosting Meta's compact, highly efficient LLaMA 3.2:1b locally. Running in the same network or Docker compose cluster as n8n, it delivers:

  • Zero Per-Token Billing: Run 1,000 or 100,000 iterations without accumulating cloud API invoices.
  • Low-Latency Inference: The 1B quantized architecture generates sharp 120-word cold email bodies in under 1.4 seconds on modest hardware.
  • Strict Data Sovereignty: Lead records and outbound message bodies never traverse external AI vendors.

Real-Time Intelligence with Tavily AI Search

A key failure of automated outreach is hallucinating irrelevant company facts. In mail_outreach.json, the n8n AI Agent node is granted direct tool execution rights over the Tavily Search API:

  1. The agent takes the lead's company name and executive title from Google Sheets.
  2. It formulates an exploratory search query (e.g., "Acme Corp recent AI product launches and engineering stack 2025").
  3. Tavily returns filtered, high-relevance semantic snippets of recent press releases and tech blogs.
  4. The Ollama model synthesizes a custom opening sentence referencing the company's actual recent achievements.

Google Sheets Schema & Idempotency Protection

To prevent sending duplicate emails to the same prospect, the spreadsheet is designed with a state machine:

Name Email Company Title Status row_number
Alex Mercer alex@example.com Acme Corp VP of Engineering Pending 2
Sarah Connor sarah@skynet.ai Cyberdyne Systems Head of AI Sent 3

The n8n trigger filters with Status != 'Sent' AND Email IS NOT EMPTY. As soon as the Gmail node dispatches, the Google Sheets node immediately marks that row as Sent before invoking the sleep delay.

Code & JavaScript Sanitization Node

The core parser node in n8n cleans raw model outputs, extracts subject headers, and appends verified portfolio URLs:

JavaScript — n8n Code Node (Sanitization & Signature) 
// Node: Parse & Sanitize Email Draft
const rawOutput = $node["AI Agent"].json.output || "";
const lead = $node["Loop Over Items"].json;

// Extract Subject Line from LLM text
const subjectMatch = rawOutput.match(/Subject:\s*(.*)/i);
const subject = subjectMatch ? subjectMatch[1].trim() : `Collaboration with ${lead.Company}`;

// Clean body and sanitize unwanted conversational chatter
let cleanBody = rawOutput.replace(/Subject:.*\n/i, '').trim();

// Append verified personal portfolio signature
const signature = `\n\nBest regards,\n${lead.Sender_Name || 'Tusha Rahul'}\nApplied AI/ML Engineer\nPortfolio: https://tusharahul.netlify.app\nGitHub: https://github.com/Rahul6158`;

return {
  json: {
    to: lead.Email,
    recipientName: lead.Name,
    company: lead.Company,
    subject: subject,
    body: cleanBody + signature,
    rowNumber: lead.row_number
  }
};
